# Data Analytics Project: Customer Shopping Behavior Analysis

## Overview
This project focuses on analyzing customer shopping behavior using Python, SQL Server, and Power BI. It covers the complete data analytics workflow, from loading and cleaning raw data to performing exploratory data analysis (EDA), writing SQL queries, building an interactive dashboard, and presenting key insights.

The objective is to transform raw customer shopping data into meaningful insights that support data-driven decision-making.

## Project Workflow
1. Loaded the dataset using Python.
2. Cleaned and preprocessed the data to improve data quality.
3. Performed exploratory data analysis (EDA) to understand customer behavior and identify patterns.
4. Imported the data into SQL Server and executed SQL queries for analysis.
5. Built an interactive Power BI dashboard to visualize key performance indicators (KPIs) and trends.
6. Prepared a PowerPoint presentation summarizing the analysis and key findings.

## How to Run

### 1. Clone the Repository
```bash
git clone <your-repository-url>
cd <your-project-folder>
```

### 2. Install Python Dependencies
Make sure Python is installed, then run:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 3. Load and Analyze the Dataset
- Place the dataset in the appropriate project folder.
- Open the Jupyter Notebook or Python script.
- Update the dataset path if required.
- Run the cells to clean and analyze the data.

### 4. Run SQL Queries
- Install and configure Microsoft SQL Server.
- Import the cleaned dataset into your database.
- Open the provided SQL script in SQL Server Management Studio (SSMS).
- Execute the queries to perform the analysis.

### 5. Open the Power BI Dashboard
- Open the `.pbix` file using Power BI Desktop.
- Update the data source connection if necessary.
- Refresh the dataset to load the latest data.

### 6. View the Presentation
Open the PowerPoint file included in the repository to review the project methodology, visualizations, and findings.
